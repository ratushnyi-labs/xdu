  shapes for LICENSE, `Cargo.toml`, the `.github/` tree (CODEOWNERS, SECURITY.md, issue
  and PR templates, workflows), `.gitignore`, `.gitattributes`, `.dockerignore`, `.env`,
  README, CONTRIBUTING, CHANGELOG, `Dockerfile`, `docker-compose.yml`, and the
  `scripts/` set. Trace: TASK-007-A findings + N1, N2, N3, N4, N5, N6.
- **AC-2: 6-target release pipeline produces stripped binaries ≤ 1.5 MiB each.** Targets:
  `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, `x86_64-pc-windows-msvc`,
  `aarch64-pc-windows-msvc`, `x86_64-apple-darwin`, `aarch64-apple-darwin`. Trace:
  N6, N8a, N8b, I, N7, N9; end-to-end verified by Q + BUG-005. Final transcript
  `docs/audits/cross-build-2026-06-03-after-bug005-fix.md` records 6 / 6 PASS with the
  largest binary at 766 632 B (`x86_64-unknown-linux-musl/xdu`, ~48.7 % of the budget).
- **AC-3: Read-only invariant (BR-001) preserved across all polish + new features.**
  Trash mode (TASK-007-J), drives picker (TASK-007-H), lock-holder enumeration
  (TASK-007-K), and every other feature leaf either stays read-only or is gated behind
  an explicit user opt-in (`--trash`, modal confirmation defaulting to `[ No ]`, etc.).
  Trace: J, H, K Specks and their `## SEC ACs` blocks.
- **AC-4: Test suite is green and the coverage baseline is recorded.** ≥ 106 tests pass
  (97 unit + 6 integration + 3 snapshot). Baseline 74.06 % workspace-wide line coverage
  is captured in `docs/audits/coverage-baseline-2026-06-03.md`. Trace: F, G, P.
- **AC-5: Dependency advisory scan run and verdict recorded with explicit user approval
  for any surviving advisories before publish.** `scripts/audit.sh` runs cleanly in
  Docker; surviving informational warnings are enumerated with rationale in
  `docs/audits/dependency-audit-2026-06-03.md` (currently 2 informational warnings —
  RUSTSEC-2024-0436 `paste 1.0.15` unmaintained, RUSTSEC-2026-0002 `lru 0.12.5` unsound
  — both transitive via `ratatui 0.29.0`, flagged for the O gate). Trace: P.
- **AC-6: TUI snapshot harness locks in rendered output.** Golden frames stored under
  `docs/ui-baselines/snapshots/` and exercised by `tests/snapshot_test.rs`. Trace: F.
- **AC-7: Multilingual user manuals shipped.** `docs/user-manual-{en,ua,es,fr,it,pt}.md`,
  machine-translated for v0.1.0 with a per-file header flag pending human review. Trace:

  this AC is a forward dependency that O must verify before publish.**
- **AC-8: Final publish actions are CRR-3-gated.** `git tag v0.1.0`, `git push` to the

## Cross-cutting SEC ACs

- **SEC-1: Stealth identity preserved (§5.4)** across every commit message, doc,
  shipping artefact, code comment, test name, and snapshot baseline produced under
  TASK-007. No `Co-Authored-By: Claude`, no "Generated by AI" banners, no agent or
  vendor names anywhere a user can see. Verification: TASK-007-R2's audit transcript
  `docs/audits/stealth-identity-2026-06-03.md` records the §5.4 sweep verdict before
  the O gate fires.
- **SEC-2: §8.2 host isolation preserved.** Every build, test, audit, and coverage run
  goes through Docker (`docker compose run --rm ...`). No host-side `cargo install` of
  shipping tooling for repo-state changes; the only permitted host installs are the
  developer's personal dev environment (their own laptop's editor / Rust toolchain),
  never anything the repo or CI depends on.
- **SEC-3: No new shipping crate dependencies** added across the publishing-prep work.
  The runtime dependency tree at v0.1.0 = `crossterm 0.28` + `ratatui 0.29` only. All
  tool installs — `cargo-llvm-cov`, `cargo-audit`, `cargo-xwin`, `cargo-zigbuild`,
  `xwin`, `zig` — are build-time / dev-only and live inside the `Dockerfile` `base` and
  `cross-tools` stages.
